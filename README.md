# Roller Coaster EDA

Exploratory data analysis on a roller coaster dataset from Kaggle.

## Dataset
Source: https://www.kaggle.com/datasets/robikscube/rollercoaster-database?resource=download

## What I did
- Cleaned the data (removed duplicates, fixed data types, handled missing values)
- Explored it with histograms, scatter plots, and a heatmap
- Looked for patterns in speed, height, and year opened

## Tools
Python, pandas, NumPy, Matplotlib, Seaborn

## How to run
Open `eda.ipynb` in Jupyter Notebook and run all cells.
